Case Study: Distributed Computing in Gaming

What happens when a player left-clicks to shoot in Valorant?

Step 1: The Left Click (Local Prediction)

The player clicks. To prevent the game from feeling laggy, the client immediately plays a gunshot animation locally.

Player Client
⭐ LEFT CLICK!
Target (Local Illusion)

Step 2: How Data Travels

The local shot is just an illusion. The actual "Fire Request" data must travel across the Internet using standard network protocols.

Player Client
INTERNET
UDP Game Data
Game Server

Step 3: Server Processing (Authority)

The game server receives the packet. It is the only authority that can decide if the shot actually hit anything.

Game Server
1. Receive Fire Request
2. Check Player Positions
3. HIT CONFIRMED

Step 4: State Synchronization

The server sends the "Updated Game State" back across the network to all clients, synchronizing everyone's reality.
